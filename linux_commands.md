### права доступа 

chmod

Разберем права:
d - Directory, если там пусто (-), то это ФАЙЛ

Первая тройка (rwx) - права для меня (владельца)
Вторая тройка (rwx) - права для группы
Третья тройка (r-x) - права для остальных

Значение букв:
r - read - позволяет просматривать
w - write - позволяет изменять, удалять, переименовывать 
x - execute - для папок право войти внутрь (cd). Если х нет, то cd не сработает. 

Цифровые коды
r = 4
w = 2
x = 1

7 (4+2+1) = полный доступ
5 (4+1) = смотреть и входить
0 - полная изоляция 

### Команды 

last - покажет кто, когда и с какого айпи заходил на сервер (last -n 5)

sudo systemctl restart wg-quick@wg0 - перезапуск wg
sudo systemctl status wg-quick@wg0 - последние логи и статус




uptime - сколько сервер работает без перезагрузки 
df -h - сколько осталось свободного места на диске
docker ps --format "table {{.Names}}\t{{.Status}}" - форматирование для вывода списка контейнеров 
sudo vgs - показывает нераспределенное дисковое пространство

docker logs --tail 50 homeassistant - посмотреть последние 50 логов контейнера умного дома (можно заменить цифру на другую и название контейнера)
docker logs -f homeassistanr - логи в режиме реального времени (-f follow)
docker logs homeassistant - посмотреть все логи 
tail -n 20 /var/log/wg_restart.log - логи скрипта на перезапуск wg
